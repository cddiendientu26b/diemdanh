# Ứng dụng điểm danh lớp học

Hệ thống điểm danh có xác minh vị trí GPS, sử dụng Supabase + HTML/CSS/JS.

## Tính năng
- Đăng ký / đăng nhập bằng email
- Xác minh vị trí GPS (chỉ điểm danh được khi ở gần trường)
- Giới hạn 1 tài khoản / 1 thiết bị
- Giới hạn giờ điểm danh
- Xem lịch sử điểm danh cá nhân

## Cấu hình
1. Tạo dự án Supabase
2. Chạy file `schema.sql` trong SQL Editor
3. Cập nhật URL và Anon Key của Supabase vào file `app.js`
4. Deploy lên Vercel
